## Design Specificity Verdict
Category-interchangeable: every page is icon tile + h1 + grey lead + 4 stat tiles + big panel + 4-up tool-card grid. Cover the logo and nothing says career or India. The product's real character (CTC, notice period, PF/UAN, campus cut-offs, aptitude, deal-breakers, red flags) is buried below the fold. Detector: 18 warnings (14 ai-color-palette = accent on heading icons, mostly benign; 4 side-tab borders, 2 real duplicates). Overlay: nested cards (tracker, offers), 9 placeholder contrast failures (2.9:1, systemic `placeholder:text-zinc-400`), orange grade chips 3.6:1, stray one-word last lines, global bounce easing. Body contrast passes AA in both themes; 11 font sizes on Today; 48-55 sub-44px touch targets per phone page; no horizontal overflow.

## Priority Issues
- [P0] Today: false network alarm and no single focus. Fix: per-section neutral error states; one "next move" hero; remove explainer/quick actions/tool grid. ($impeccable distill, $impeccable harden)
- [P0] Job room is an unscannable wall with 3 nav layers; stage chips break mid-word on phones. Fix: one header, one-line stage, stage-relevant content first, disclosures with counts. ($impeccable layout, $impeccable adapt)
- [P1] Tool sprawl and four overlapping navigation systems. Fix: one home per tool, ≤3 contextual tools per hub, one searchable Tools page + Ctrl K; Jobs tabs to Discover/Tracker/Auto-apply. ($impeccable distill)
